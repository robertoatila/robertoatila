## ✦ Projeto em destaque

### 🧾 MarkitosSystem — Sistema de Faturamento e Estoque

Aplicação full-stack para gestão de **empresas, usuários, clientes, fornecedores, produtos, faturas, movimentações e estoque**.

<div align="center">

![Next.js](https://img.shields.io/badge/Next.js_15-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)
![React](https://img.shields.io/badge/React_19-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![TypeScript](https://img.shields.io/badge/TypeScript_5-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Java](https://img.shields.io/badge/Java_17-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Spring Boot](https://img.shields.io/badge/Spring_Boot_3.5-6DB33F?style=for-the-badge&logo=springboot&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL_8-4479A1?style=for-the-badge&logo=mysql&logoColor=white)

</div>

**Stack atual:** `Next.js 15.5.21` · `React 19.1.0` · `TypeScript 5` · `Tailwind CSS 4` · `Java 17` · `Spring Boot 3.5.16` · `Spring Security` · `Spring Data JPA` · `MySQL 8` · `Flyway` · `Docker`

**Alguns pontos técnicos do projeto:**

- 🔐 autenticação JWT com cookie HttpOnly e senhas com BCrypt;
- 🛡️ autorização baseada em papéis no backend e isolamento de dados por empresa;
- 📦 estoque com reserva, baixa, estorno, depósitos, lotes, Kardex e inventário;
- 🧾 faturas de venda e compra integradas às movimentações de estoque;
- 🗃️ migrations versionadas com Flyway;
- 🧪 testes de backend/frontend, E2E com Playwright e acessibilidade com Axe;
- 🐳 ambiente local reproduzível com Docker.

> 🔒 O repositório principal do MarkitosSystem permanece privado durante o desenvolvimento.
