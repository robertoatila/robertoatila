## Projeto principal

### MarkitosSystem — Sistema de Faturamento e Estoque

Aplicação full-stack para gestão de empresas, usuários, clientes, fornecedores, produtos, faturas, movimentações e controle de estoque.

**Stack verificada no estado atual do projeto:**

`Next.js 15.5.21` · `React 19.1.0` · `TypeScript 5` · `Tailwind CSS 4` · `Java 17` · `Spring Boot 3.5.16` · `Spring Security` · `Spring Data JPA` · `MySQL 8` · `Flyway` · `Docker`

**Recursos e práticas presentes no projeto:**

- autenticação JWT com cookie HttpOnly;
- BCrypt para armazenamento de senhas;
- autorização baseada em papéis no backend;
- isolamento de dados por empresa;
- gestão de clientes, fornecedores, produtos e usuários;
- faturas de venda e compra;
- reserva, baixa, estorno e entrada de estoque vinculados às faturas;
- depósitos, lotes, Kardex e inventário;
- migrations de banco com Flyway;
- testes de backend e frontend;
- testes E2E com Playwright;
- verificações de acessibilidade com Axe;
- execução local com Docker.

> O repositório do MarkitosSystem é privado.
