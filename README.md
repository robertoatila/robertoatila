## Projeto em destaque

### MarkitosSystem — Sistema de Faturamento e Estoque

Sistema full-stack para gestão de empresas, usuários, clientes, fornecedores, produtos, faturamento e estoque.

**Stack atual:** `Next.js 15` · `React 19` · `TypeScript` · `Java 17` · `Spring Boot 3.5` · `Spring Security` · `MySQL 8` · `Flyway` · `Docker`

**Principais pontos técnicos:**

- autenticação JWT por **cookie HttpOnly** e senhas com BCrypt;
- **RBAC server-side** e isolamento de dados por empresa;
- faturamento de vendas e compras integrado ao estoque;
- reserva, baixa, estorno, lotes, depósitos, Kardex e inventário;
- migrations versionadas com **Flyway**;
- frontend em **Next.js + React + TypeScript strict**;
- testes com **JUnit, Mockito, Vitest, Testing Library, Playwright e Axe**;
- configuração reproduzível com Docker e práticas de hardening para ambientes publicados.

> O código principal permanece em repositório privado enquanto o projeto está em desenvolvimento.
