## Projeto em destaque

### MarkitosSystem

Sistema de faturamento e estoque

Aplicação full-stack para gestão de **empresas, usuários, clientes, fornecedores, produtos, faturas, movimentações e estoque**.

#### Base técnica

<code>Next.js 15.5.21</code>
<code>React 19.1.0</code>
<code>TypeScript 5</code>
<code>Tailwind CSS 4</code>
<code>Java 17</code>
<code>Spring Boot 3.5.16</code>
<code>Spring Security</code>
<code>Spring Data JPA</code>
<code>MySQL 8</code>
<code>Flyway</code>
<code>Docker</code>

#### Pontos técnicos

- Autenticação JWT com cookie HttpOnly e senhas com BCrypt.
- Autorização baseada em papéis no backend e isolamento de dados por empresa.
- Estoque com reserva, baixa, estorno, depósitos, lotes, Kardex e inventário.
- Faturas de venda e compra integradas às movimentações de estoque.
- Migrações de banco versionadas com Flyway.
- Testes de backend e frontend, E2E com Playwright e acessibilidade com Axe.
- Ambiente local reproduzível com Docker.

> O repositório principal do MarkitosSystem permanece privado durante o desenvolvimento.
